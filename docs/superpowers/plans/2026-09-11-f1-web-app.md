# F1 Race Hub Standalone Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create an autonomous, zero-dependency, single-file Single Page Application (SPA) `index.html` providing a complete Formula 1 dashboard, live timing tower (P1–P22), interactive Canvas track map, and championship standings.

**Architecture:** A self-contained HTML5/CSS3/ES6+ web application using CSS Custom Properties for the F1 Dark Racing theme, a reactive Observer Micro-Store for state management, an HTML5 Canvas vector engine for circuit and car rendering, and an offline-first data layer with realistic 2024 season data and background API synchronization.

**Tech Stack:** HTML5, CSS3 Grid/Flexbox, Vanilla JavaScript (ES2020+), HTML5 2D Canvas API, LocalStorage API, Node.js (test verification).

**Spec:** [docs/superpowers/specs/2026-09-11-f1-web-app-design.md](file:///c:/VIBE-CODE/docs/superpowers/specs/2026-09-11-f1-web-app-design.md)

## Global Constraints

* Single-file standalone web document: `web/index.html` (and mirrored root `index.html` for GitHub Pages).
* Zero external script or font dependencies: no CDN dependencies, completely functional over `file://` or offline.
* Full 22-driver grid (P1–P22) in Live Timing and Standings.
* F1 Dark Racing Theme palette: `#101014` background, `#1B1B22` surface, `#E10600` primary red, Pirelli tyre tokens (`#FF1801`, `#FFD200`, `#FFFFFF`, `#39B54A`, `#00A3E0`).
* Anti-AI-slop & engineering rigor: precise naming, varied sentence structure, no banned AI clichés.
