# Архитектурная спецификация: F1 Race Hub Web Version (Single-File SPA)

Дата: 2026-09-11  
Статус: Утверждено  
Цель: Предоставление автономной веб-версии F1 Race Hub без внешних зависимостей сборки с мгновенным стартом на мобильных и десктопных браузерах.

---

## 1. Назначение и контекст системы

Веб-версия F1 Race Hub решает задачу оперативного доступа к гоночной информации и телеметрии Formula 1 без необходимости установки APK на мобильные устройства. Приложение оформлено как полностью автономный одностраничный документ (`index.html`), сочетающий стили, разметку и логику работы в едином файле.

### Ключевые требования:
* **Автономность:** 0 внешних библиотек и CDN-скриптов; запуск по протоколу `file://` либо через статический веб-сервер / GitHub Pages.
* **Пелотон P1–P22:** поддержка 22 пилотов (20 постоянных гонщиков сезона 2024 и ключевые резервисты) в башне тайминга и зачете чемпионата.
* **Отказоустойчивость:** встроенный датасет сезона 2024 (Гран-при Италии, Монца), обеспечивающий 100% работоспособность интерфейса при отсутствии подключения к сети или блокировках CORS.
* **Адаптивность:** интерфейс оптимизирован под мобильные экраны (фиксированная нижняя панель навигации 56px) и десктоп (верхний таб-бар).

### 2.2. Состав экранов
Приложение содержит 4 функциональных экрана, управляемых через хэш-маршрутизацию (`#dashboard`, `#timing`, `#trackmap`, `#standings`):

1. **Dashboard (`#screen-dashboard`):**
   * Баннер ближайшего Гран-при (название этапа, страна, трасса).
   * Таймер обратного отсчета в реальном времени с 4 блоками: Дни, Часы, Минуты, Секунды.
   * Список всех 5 сессий уикенда (FP1, FP2, FP3, Qualifying, Grand Prix) с локализацией времени под часовой пояс браузера пользователя (`Intl.DateTimeFormat`).
   * Кнопка переключения напоминаний к сессиям с сохранением в `localStorage`.

2. **Live Timing (`#screen-timing`):**
   * Баннер статуса заезда Race Control с интерактивным переключением режимов флагов: `GREEN` (Зеленый флаг), `YELLOW` (Желтый флаг / VSC), `RED` (Красный флаг).
   * Таблица позиций пелотона P1–P22 с фиксированной строкой заголовков.
   * Колонки: Позиция, Цветовой маркер команды (4px), Номер и трехбуквенный код пилота (VER, NOR, LEC и т.д.), Отставание от лидера (`LEADER` для P1, `+X.XXXs` для P2+), Бейдж шины Pirelli с количеством кругов на текущем комплекте.

3. **Track Map (`#screen-trackmap`):**
   * Элемент `<canvas id="trackCanvas">` с масштабированием буфера под `window.devicePixelRatio`.
   * Векторная отрисовка трассы: асфальтовое полотно `#23232C` шириной 16px, гоночная траектория `#3F3F4E`, стартово-финишная черта белого цвета.
   * Анимация движения 10 лидирующих болидов по замкнутой траектории через `requestAnimationFrame`.
   * Интерактивное управление: кнопка паузы/запуска симуляции, селектор скорости (1x / 2x).
   * Автоматическая остановка цикла анимации при неактивной вкладке (`document.hidden`).

4. **Standings (`#screen-standings`):**
   * Сегментированный переключатель вкладок: «Пилоты» и «Конструкторы».
   * Таблица личного зачета: 22 пилота, позиция, код, полное имя, команда, количество очков и побед.
   * Таблица Кубка конструкторов: 10 команд с официальными цветами, очками и победами.

## 3. Управление состоянием и сетевой слой (State & Network)

### 3.1. Структура центрального хранилища (Store)
```javascript
const Store = {
  state: {
    activeTab: 'dashboard',
    nextGrandPrix: null,
    sessions: [],
    timing: [],      // 22 пилота
    standings: {
      drivers: [],   // 22 пилота
      constructors: [] // 10 команд
    },
    flagStatus: 'GREEN',
    simulationRunning: true,
    simulationSpeed: 1,
    alarms: {}
  },
  subscribers: new Set(),
  subscribe(fn) { this.subscribers.add(fn); },
  notify() { this.subscribers.forEach(fn => fn(this.state)); }
};
```

### 3.2. Стратегия работы с данными
1. **Bootstrap Phase (0 ms):** Синхронная инициализация Store из встроенного объекта `EMBEDDED_2024_DATA`. Интерфейс отрисовывается без сетевых задержек.
2. **Network Phase:** Вызов `fetch` с `AbortController` (таймаут 3000 мс) к эндпоинтам:
   * Календарь: `https://api.jolpica.com/ergast/f1/current.json`
   * Интервалы: `https://api.openf1.org/v1/intervals?session_key=latest`
3. При перехвате ошибки `TypeError` (CORS) или таймаута индикатор статуса сети фиксирует `OFFLINE (CACHED)`, а приложение продолжает работу на встроенном кэше.
