# F1 Race Hub

Нативное Android-приложение для мониторинга событий Формулы-1 с офлайн-синхронизацией, таймингом в реальном времени и интерактивной картой трассы.

## Архитектура и стек

Архитектура приложения построена по стандартам Clean Architecture с разделением на слои: presentation, domain, data и core.

* **Платформа и язык:** Kotlin 2.0.20, Android SDK (minSdk 26, targetSdk 35)
* **Пользовательский интерфейс:** Jetpack Compose (BOM 2024.09.00), Material 3, векторная отрисовка трека на Canvas
* **Загрузка изображений:** Coil 3.0.0-rc01 (coil3.compose.AsyncImage)
* **Сетевой клиент:** Ktor 2.3.12 (OkHttp engine, kotlinx.serialization.json)
* **Локальная база данных:** Room 2.6.1 SQLite с каскадными внешними ключами
* **Фоновые напоминания:** AlarmManager.setExactAndAllowWhileIdle (RTC_WAKEUP) с обработчиком перезагрузки BootCompletedReceiver
* **Внедрение зависимостей:** Koin 3.5.6

## Внешние API

1. **Jolpica F1 API (Ergast v2):** Календарь сезона, расписание свободных заездов, квалификаций, спринтов и гонок, личный зачет и кубок конструкторов.
2. **OpenF1 API:** Интервалы между болидами, составы шин (Pirelli Soft/Medium/Hard/Inter/Wet), радиосообщения дирекции гонки и координаты болидов на треке.

## Основные экраны

* **Главная (Dashboard):** Таймер обратного отсчета до ближайшей сессии с посекундным обновлением, расписание гоночного уикенда, переключатели точных будильников за 15 минут до старта.
* **Тайминг (Live Timing):** Лидерборд P1–P10 с цветовой индикацией команд, отставанием от лидера, составом шин и текущим флагом сессии (Green, Yellow, Red).
* **Карта трассы (Track Map):** Отрисовка трассы на холсте Jetpack Compose с отображением позиций болидов и горизонтальной лентой пилотов.
* **Чемпионат (Standings):** Таблицы личного зачета с портретами гонщиков и кубка конструкторов с набранными очками.
